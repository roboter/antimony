Antimony 0.9.7
--------------

## Features
- Scaled ViewCube orientation gizmo 2x for enhanced visibility and interaction
- ViewCube face labels rotate with 3D orientation in real-time
- Refined label typography and sizing (full "BOTTOM" label fits face cleanly)

## Windows Packaging & Reliability
- Recursive transitive DLL bundler (`deploy-windows.py`) ensures all runtime dependencies (`libdouble-conversion`, `libpcre2`, `libzstd`, `libicu`, `libharfbuzz`, `libfreetype`, etc.) are included in Windows release archives
- Full standalone Python standard library packaging for isolated Windows execution
- Build script and CI workflow hardening for MSYS2 UCRT64 toolchain

## Linux Release Builds
- Automated GitHub Actions Linux CI/CD release workflow (`linux-build.yml`) on Ubuntu 22.04
- Standalone portable tarball package (`antimony-linux-x86_64.tar.gz`) with launcher script and bundled python node libraries
- Native Debian/Ubuntu package (`antimony-linux-amd64.deb`) for one-command installation
- Flexible Boost Python library discovery supporting multiple Linux distribution conventions
