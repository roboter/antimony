Antimony 0.9.6
--------------

## Features
- Interactive 3D ViewCube orientation gizmo in viewport with smooth animated face snapping
- High-DPI physical pixel texture sizing and RGBA8888 buffer anti-aliasing
- Subpixel floating-point positioning to eliminate jumpy rendering during zoom and pan
- Automated Windows and macOS GitHub CI/CD release builds

## Bugfixes
- Fix 2D circle rotation symmetry and infinite Z bounding behavior
- Eliminate visual popping in progressive multi-stage refinement rendering
- Standardize build output directly into build/antimony
